## Weather App (JavaScript Project)

- This project is a simple Weather Web Application built using HTML, CSS, and JavaScript. It fetches real-time weather data from a weather API and displays information such as temperature, humidity, wind speed, and weather conditions for any searched city.
The goal of this project is to practice API integration, JavaScript DOM manipulation, async functions, and responsive UI design.

## Features

Search weather by city name
Real-time weather data using API
Temperature, humidity, and wind details
Dynamic weather icons
Error handling for invalid city names
Clean and responsive UI
